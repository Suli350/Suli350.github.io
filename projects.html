A robotic delivery system with four parts working together: a Kinova Gen3 arm that sorts requested items into a tray using ArUco marker detection, a Fetch Mobile Manipulator that carries the tray to the user and back, a backend decision engine that plans the pipeline, and a web interface that ties it all together.Ein robotisches Liefersystem aus vier zusammenwirkenden Komponenten: ein Kinova Gen3-Arm, der angeforderte Artikel mithilfe von ArUco-Markererkennung in ein Tablett sortiert, ein Fetch Mobile Manipulator, der das Tablett zum Nutzer und zurück bringt, eine Backend-Entscheidungslogik, die den Ablauf plant, sowie eine Weboberfläche, die alles miteinander verbindet.نظام توصيل روبوتي مكوّن من أربعة أجزاء تعمل معاً: ذراع Kinova Gen3 يقوم بفرز العناصر المطلوبة في صينية باستخدام تقنية كشف علامات ArUco، وروبوت Fetch Mobile Manipulator الذي ينقل الصينية إلى المستخدم ويعيدها، ومحرك قرارات في الخلفية يخطط لسير العمل، وواجهة ويب تربط كل ذلك معاً.
